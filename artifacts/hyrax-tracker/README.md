# Hyrax October Tracker

Static PWA. Data lives in the browser (`localStorage`). Works offline after first load.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy (Vercel)

From this folder:

```bash
npx vercel
```

Or push the folder to GitHub and import the repo in Vercel. Framework preset: Other. Output is the repo root of this app.

## Use

- Week 1 is pre-filled from the October brief (5 goals). Weeks 2–4 are empty slots.
- Add goals/milestones, set status and due date, write notes.
- Export JSON for backup or another device. Import to restore.
- Reset seed restores the original Week 1 content and wipes local edits.

Install as an app via the browser “Add to Home Screen” / install prompt.
